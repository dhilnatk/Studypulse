# 📚 StudyPulse – Smart Exam Readiness Analyzer

StudyPulse is an interactive web application built with Python and Streamlit
to help students understand their exam readiness.

## ✨ Features

- 📖 Track syllabus completion
- ⏱️ Enter daily study hours
- 📅 Set an exam date
- 📝 Enter latest test score
- 💬 Rate confidence in a subject
- 🎯 Calculate an overall exam readiness score
- 💡 Get personalized study recommendations
- 📅 View days remaining until the exam

## 🛠️ Technologies Used

- Python
- Streamlit

## 🎓 Purpose

This project was created as a beginner-friendly mini project
to gain practical experience in Python and interactive application development.

- Subject priority analysis
